# 1079 · Высота

Кооперативная игра на выживание по мотивам похода группы Дятлова (январь–февраль 1959). Ночь 1 февраля: двое путников выходят от ночёвки у лабаза в долине Ауспии, им надо подняться ≈1,7 км к палатке на склоне Холатчахля, пока не кончилось тепло. Мешают темнота, пурга и Менк — вымышленный лесной великан из мансийских преданий.

Движок — Unity 6 (**6000.0.84f1**), C#, встроенный рендер (Built-in RP), PhysX, Netcode for GameObjects. Весь мир, префабы и сцена генерируются кодом редактора из данных в репозитории.

> Работаешь в репозитории как агент (Claude Code и т. п.)? Начни с **[CLAUDE.md](CLAUDE.md)**: там окружение, команды и правила совместной работы.

## Быстрый старт

1. Поставь Unity Hub и редактор **6000.0.84f1** с модулями *Mac Build Support (Mono)* и/или *Windows Build Support (Mono)*.
2. Склонируй репозиторий и открой его папку в Unity Hub (Add → project from disk).
3. При первом открытии редактор сам:
   - скачает пакеты;
   - построит мир в `Assets/Resources/World` (несколько минут);
   - создаст `Assets/Scenes/Main.unity`.

   Если чего-то нет, запусти в меню **1079 → Rebuild world** и **1079 → Generate prefabs and scene**.
4. Открой `Assets/Scenes/Main.unity` и нажми Play. В меню игры «Создать ночь» запускает её хостом, «Присоединиться» подключает к хосту по IP (порт 7777).

Без редактора, из терминала (редактор с проектом должен быть закрыт):

| | macOS | Windows (PowerShell) |
|---|---|---|
| Компиляция, генерация, тесты | `Tools/mac/check.command` | `powershell -ExecutionPolicy Bypass -File Tools\win\check.ps1` |
| Сборка | `Tools/mac/build.command` → `Builds/mac/1079.app` | `Tools\win\build.ps1` → `Builds\windows\1079.exe` |
| Запуск сборки в окне | `Tools/mac/run.command` | `Tools\win\run.ps1` |
| Тесты ядра без Unity | `cd Tools/CoreTests && dotnet run` | то же (нужен .NET 8 SDK) |

Логи пишутся в корень проекта: `unity-check.log`, `unity-tests.xml`, `build.log`, `build-editor.log`, `player.log`. В git они не попадают.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки, Shift | идти, бежать |
| V (или F7) | первое / третье лицо |

| 2 ещё раз | трубчатый фонарик ↔ динамо-«жучок» |

| Tab | рюкзак: свой, лежащий в снегу или на спине напарника |
| G | снять рюкзак / надеть лежащий рядом |
| R | поднять то, что лежит рядом / убрать из рук в рюкзак |
| X | бросить то, что в руках |
| N | мини-карта |
| Esc | пауза |
| F2 | архивный слой (версии, ориентиры, линия следов) |
| F3 | осмотр мест событий камерой |
| F4 / F5 / F6 | для отладки: смотреть на Менка / разбудить его / перевести часы ночи на минуту вперёд (F5 и F6 только у хоста) |

## Что есть в игре

- **Мир.** Участок 4,1 × 4,1 км вокруг Холатчахля на рельефе ArcticDEM 2 м и 36 тыс. деревьев по модели высоты полога. По документам реконструированы палатка, лабаз, кедр с костром, настил и ночёвка 31 января. Подробности в [docs/MAP.md](docs/MAP.md).
- **Ночь.** Её считает хост (`NightSession` → `NightRun`): часы, метели, тепло, руки, ясность, общий костёр, исходы пары. Клиенты получают снимки состояния и протокол.
- **Атмосфера.** Настоящая темнота, пурга с нулевой видимостью, качающиеся деревья. Звук синтезируется при запуске, сэмплов нет. Подробности в [docs/ATMOSPHERE.md](docs/ATMOSPHERE.md).
- **Менк.** Притворяется деревом, бьёт палатку и охотится за игроками; луч фонаря заставляет его замереть. Подробности в [docs/ATMOSPHERE.md](docs/ATMOSPHERE.md#менк-вымысел-игры).
- **Снаряжение эпохи.** Калька-карта, компас Адрианова, трубчатый фонарик и «жучок». Подробности в [docs/ITEMS.md](docs/ITEMS.md).
- **Пролог и дальнейшие планы.** Сюжет — [docs/PROLOGUE.md](docs/PROLOGUE.md), сценарий — [docs/SCRIPT.md](docs/SCRIPT.md), бэклог механик — [docs/BACKLOG.md](docs/BACKLOG.md).

## Steam (необязательно)

1. Добавь в `Packages/manifest.json` транспорт сообщества:
   `"com.community.netcode.transport.facepunch": "https://github.com/Unity-Technologies/multiplayer-community-contributions.git?path=/Transports/com.community.netcode.transport.facepunch"`
2. Добавь define `STEAM_FACEPUNCH` в Player → Scripting Define Symbols. Сборка `Height1079.Steam` компилируется только с этим символом.
3. Положи рядом с исполняемым файлом (и в корень проекта для Play) файл `steam_appid.txt` с числом `480` (тестовый AppID) или своим AppID. Steam-клиент должен быть запущен.

Steam-слой вживую ещё не проверялся.

## Честные границы

- Позиции игроков сервер принимает от их владельцев, как в браузерной версии.
- Ragdoll нет.
- У Менка простая логика: он ходит по прямой и проходит сквозь стволы.
- Исторические точки взяты из архивных данных. Персонажи ночи и их исходы вымышлены, Менк — вымысел.
